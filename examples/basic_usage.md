# Basic Usage Examples

## Run an autonomous task
```bash
litert-agent run "Create a Python script that prints the CPU load every 5 seconds"
```

## Interactive chat
```bash
litert-agent chat
```

## Full console
```bash
litert-agent web          # open http://127.0.0.1:8765
```

## Inspect the agent
```bash
litert-agent status --json
litert-agent health
litert-agent doctor
litert-agent tool test terminal
litert-agent security approvals
```
